SCOLA KEEPSAKE PACKAGE

Upload the contents of this folder as the root of a static website. Do not upload the workspace root.

Open the hosted keepsake-card.html page to print the A5 card. Its QR code targets index.html automatically. The local preview URL is not suitable for printing.

The site is public to anyone with its URL. The narration is a generated Microsoft Zira voice.

QRCode.js is included under the MIT license in QR-CODE-LICENSE.txt.
